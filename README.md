# Maya's Personal Portfolio Website

This portfolio shows my completion of the year-long Orange Belt Program at iCode Columbia. It is a full record of the web technologies, coding logic, and graphic design methods that I learned this year.

This website shows my coding projects, game designs, backend tests, and graphic design work.

## iCode Columbia Orange Belt Lessons

The iCode Orange Belt Program is a year-long course about web technology, software tools, and digital design. This year, I went from learning basic styles to building interactive games and server programs.

### Core Concepts I Learned

#### 1. Front-End Web Design
*   **Semantic HTML5 Elements**: I learned to use organized tags like header, nav, section, article, and footer. This helps search engines read the page better and makes the website accessible for everyone.
*   **Responsive CSS3 Grid and Flexbox**: I built grids and boxes that let the website change its size smoothly. It works perfectly on computers, tablets, and phones.
*   **CSS Variable Systems**: I used root color variables to change the colors of the site in real time when a user clicks the theme button.
*   **Browser Memory and Events**: I wrote JavaScript to track actions on the page and save theme choices. Using localStorage, the browser remembers if the user prefers light mode or dark mode even if they reload the page.
*   **Interactive Star Background**: I coded a custom starfield background using the HTML5 canvas. The stars float around and gently pull toward your mouse cursor. If you click on the empty space, a burst of new twinkling stars will appear. The stars change colors automatically depending on the active theme so they are always visible.

#### 2. Back-End Logic
*   **Server Programming with PHP**: I built web layouts using PHP commands, loop statements, and dynamic pages.
*   **Page Requests**: I learned how web browsers and servers talk to each other to load and display page content.

#### 3. Graphic Design and Visual Rules
*   **CRAP Design Steps**: I learned to use Contrast, Alignment, Repetition, and Proximity. These rules help make text easy to read and create a balanced design.
*   **Branding Assets**: I created corporate assets including custom logos, color palettes, business cards, and slide presentations.
*   **Micro-Interactions**: I created hover animations, smooth page menus, and clean sliding menus.

## Project Structure

*   **index.html**: The main home page structure.
*   **_config.yml**: Jekyll settings for hosting on GitHub Pages.
*   **css/style.css**: Core theme variables, main layout, and starfield position styles.
*   **css/utilities.css**: Spacing, buttons, project cards, and the custom beach/mountain toggle styling.
*   **js/script.js**: Slide menus, theme memory, and the animated starfield canvas.
*   **assets/**: Contains all site images like logos, profile pictures, and custom toggle backgrounds.

## How to Run Locally

1. Clone or download this project repository.
2. Double-click index.html at the root folder to open it in your browser. You can also use a VS Code extension like Live Server for the best testing experience.
